⚙️ Outlook 사전 설정 (필수!)

서명 설치 전에 반드시 아래 설정을 확인하세요:

  1. HTML 형식 강제:
    Outlook → 파일 → 옵션 → 메일
    → "이 형식으로 메시지 작성" → HTML 선택
  2. 일반 텍스트 답장 해제:
    같은 화면에서
    → "일반 텍스트로 보낸 메시지에 회신할 때 일반 텍스트 형식 사용" → 체크 해제
  3. 이미지 자동 다운로드 (선택):
    파일 → 옵션 → 보안 센터 → 보안 센터 설정
    → 자동 다운로드
    → "HTML 전자 메일 메시지나 RSS 항목에서 그림을 자동으로 다운로드 안 함" → 체크 해제

📧 Gmail 설치 (복사 붙여넣기)

  1. 위에서 Gmail 모드 선택
  2. Copy Email Signature 클릭
  3. Gmail → ⚙️ → 모든 설정 보기
  4. 서명 → + 새로 만들기
  5. 편집기 안에서 Ctrl+V
  6. 변경사항 저장

📨 Outlook Desktop 설치 ★ 권장

방법 1: 직접 설치 (3단계)

  1. 위에서 Outlook Desktop 모드 선택 → 📦 Download Outlook Package 클릭
  2. 다운로드된 ZIP 파일 압축 해제
    → .htm 파일 1개 + .txt 파일 1개 + _files 폴더 1개가 나옵니다
  3. Windows 탐색기 열기 → 주소창에 아래를 복사/붙여넣기 후 Enter:
    %appdata%\Microsoft\Signatures
    → 압축 해제한 모든 파일과 폴더를 이 안에 복사
    → 기존 파일이 있으면 덮어쓰기 하세요

✅ Outlook 완전히 종료 후 다시 실행 → 새 메일 → 서명 선택에서 확인

방법 2: 자동 설치 (더블클릭!)

  1. 📦 Download Outlook Package 클릭 → ZIP 다운로드
  2. ZIP을 압축 해제합니다
  3. 압축 푼 폴더 안의 install.bat을 더블클릭
    → 자동으로 파일 복사가 완료됩니다. "설치 완료!" 메시지 확인
  4. Outlook 재시작 → 새 메일 → 서명 선택

🌐 Outlook Web (Microsoft 365)

  1. Gmail 모드에서 Copy Email Signature 클릭
  2. Outlook Web → ⚙️ → 모든 Outlook 설정 보기
  3. 메일 → 작성 및 회신 → 서명 편집기에 Ctrl+V
